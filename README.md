# Technické a štatistické analýzy

Tento repozitár slúži ako portfólio inžinierskych výpočtov a simulácií so zameraním na aplikovanú mechaniku, pružnosť/pevnosť a priemyselnú štatistiku.

## Obsah projektu:
* **Analyza_nosnikov.ipynb** – Štatistická simulácia spoľahlivosti nosníka metódou Monte Carlo. Model zohľadňuje reálne výrobné tolerancie materiálu (Gaussovo rozdelenie medze klzu) a geometrie prierezu pre výpočet percentuálnej nepodarkovosti konštrukcie.
* **Fourier.ipynb** – Spracovanie signálov zo senzorov kmitania. Využitie rýchlej Fourierovej transformácie (FFT) na odhalenie skrytých frekvencií a diagnostiku porúch ložísk v hlučnom prostredí.

**Použité technológie:** Python, Google Colab, NumPy, Matplotlib, štatistické modelovanie.
